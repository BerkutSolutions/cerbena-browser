# Журнал изменений

## 1.2.6

### Расширения
- Исправлен UX импорта расширений в Windows: выбор ссылок/файлов теперь запускается через `powershell.exe` в скрытом неинтерактивном режиме без всплывающего консольного окна.
- Добавлена защита от случайного открытия модалки редактирования сразу после импорта `cerbena-extensions-links.json`.
- Улучшено профильное Chromium-расширение политики блокировок:
  - вместо стандартного `ERR_BLOCKED_BY_CLIENT` показывается фирменная страница Cerbena;
  - добавлен `service worker` для передачи контекста последней блокировки;
  - вынесена логика блок-страницы в отдельный `blocked.js` (без inline-скрипта) для совместимости с CSP в `Manifest V3`;
  - добавлены fallback-параметры `host/url` в redirect к `blocked.html`, чтобы страница всегда могла показать домен и URL.
- Убраны зацикливания блок-страницы:
  - служебный хост `cerbena.blocked.local` исключен из генерации denylist-правил;
  - отправка self-report beacon отключена для service-loop URL;
  - служебный хост запрещено блокировать через действия в журнале трафика.

### Движок
- Усилен путь silent-установки runtime через MSI в Windows: ужесточены quiet-аргументы и сокращены fallback-ветки, чтобы избежать интерактивных окон установщика на чистой системе.
- Для Chromium добавлено принудительное применение поисковой системы через `chrome_settings_overrides`, чтобы дефолтный поиск профиля не откатывался на Google.

### Личность
- Улучшен предпросмотр личности:
  - добавлены структурированные блоки вместо «сырого» JSON;
  - добавлена сводка (режим, отображаемое имя, предупреждения, блокирующие проблемы);
  - добавлены секции параметров и более читаемое отображение полей.
- Обновлены русские подписи и формулировки в связанных UI-элементах.

### Трафик
- Убрано дублирование статусов в строках трафика (`Обработан` + `allowed`): оставлен единый локализованный формат ответа.
- Удален технический подпункт запроса под адресом (например, `CONNECT`) для более чистого списка.
- Добавлен настраиваемый срок хранения истории трафика в настройках (`1 день`, `3 дня`, `1 неделя`, `2 недели`, `1 месяц`) с автоочисткой старых записей.
- Повышена надежность записи `traffic_gateway_log.json`: сохранение стало атомарным (временный файл + замена), что снижает риск повреждения лога при перезапуске.
- Введена server-side пагинация вкладки трафика:
  - frontend запрашивает только текущую страницу, а не весь журнал сразу;
  - добавлен выбор размера страницы `25 / 50 / 100`;
  - добавлены кнопки страниц;
  - отображается максимум 10 кнопок страниц, далее `...` и последняя страница.

### Профили
- Снят конфликт сохранения security-настроек у запущенного профиля: изменения сохраняются без ошибки и применяются в рантайме после перезапуска профиля.
- Добавлен безопасный повтор сохранения при version-конфликте (`profile changed by another update`) для уменьшения ложных ошибок при быстром переключении между остановкой и редактированием.
- Исправлен запуск стартовой страницы профиля в Chromium с учетом актуального launch-плана.

### Настройки UI
- Перестроен порядок карточек на вкладке «Общие»:
  - верхний ряд: «Основные настройки», «Обновления лаунчера»;
  - нижний ряд: «Состояние средств», «Состояние устройства».
- Базовые параметры поведения перенесены в соответствующую секцию «Основные».
